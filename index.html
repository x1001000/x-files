[ 02 19 26 ] // TRUTH SOCIAL // 唐納·川普 DONALD J. TRUMP

[ 關　於 // ABOUT ]

為回應川普總統對於美國政府所掌握之不明異常現象（UAP）相關資訊應予透明公開的指令，戰爭部（DOW）在國家情報總監辦公室（ODNI）的協助下，正主導跨政府部門的工作——迅速尋找、審查、識別、解密並對外公開尚未解決的 UAP 相關紀錄與歷史文件。

這是一項前所未有的歷史性工程，需要數十個機構協同運作，並審閱以紙本形式存在、橫跨數十年的數千萬筆紀錄。鑑於工程之龐大，戰爭部將以滾動方式釋出新資料——每隔數週公布一批。

本檔案庫所收錄者皆為 未　解　之　案 ——意即政府目前無法對所觀察之現象作出明確判定。原因不一而足，包括資料不足等等；戰爭部歡迎民間部門投入分析、提供資訊與專業見解。
